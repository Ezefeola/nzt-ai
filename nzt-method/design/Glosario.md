# Glosario del método

Los términos de `nzt`, con su nombre en los documentos de diseño (español) y en las skills
(inglés, A1). Cumple la regla 9 de `gestionar-skills`: un término por concepto, siempre el
mismo. No es el glosario de cada trabajo, que vive en su `Docs/glossary.md` (principio 15).

Creado el 2026-11-08. Lo marcado *propuesta* no está decidido; lo demás sí.

| Español | Inglés | Qué es |
|---|---|---|
| trabajo | work | Todo lo que la persona pidió, de principio a fin |
| unidad | unit | Una parte del trabajo que recorre el loop y termina en una parada. Decidido: `unit`, como en `nzt-software` |
| loop | loop | entender → proponer → hacer → verificar → registrar (*understand → propose → do → verify → record*) |
| tamaño | size | Cuánto proceso lleva el trabajo |
| al paso | direct | Tamaño sin plan ni estado: se hace y se reporta. *Propuesta* de nombre en inglés, como en `nzt-software` |
| con plan corto | planned | Tamaño con un plan que se aprueba una vez. *Propuesta* |
| por partes | sliced | Tamaño en que el trabajo se corta en unidades. *Propuesta* |
| aclarar | clarify | Preguntas o exploración corta antes de dimensionar un pedido difuso |
| quién hace | who does | Quién hace una unidad: el agente, la persona o los dos (*agent, person, both*) |
| criterio de hecho | done criterion | Cómo se sabe que algo terminó, acordado al principio. En los archivos, la sección *Done when* |
| parada | stop | El final de una unidad: se reporta y se espera a la persona |
| veredicto | verdict | El resultado de una parada: hecho, parcial o no logrado (*done, partial, not achieved*) |
| lote cerrado | closed batch | Varias unidades que la persona aprueba de una vez; el agente para al terminarlas |
| estado | state | Lo necesario para retomar, en `Plan/state.md` |
| archivo de herramientas | agent tools file | `Docs/agent-tools.md`: plugins, MCPs y paquetes en uso, y los rechazados |
| glosario del trabajo | work glossary | `Docs/glossary.md`: los términos clave de un trabajo |
| paquete de dominio | domain package | Un plugin aparte que suma el saber de un tema |
| default | default | Lo que el núcleo usa cuando ningún paquete aporta algo |
| tiempo fijo | fixed time | Opción de mantener el plazo y recortar alcance |
| recortable | cuttable | Lo que se puede sacar del alcance si no alcanza el tiempo. *Propuesta* |
| retro | retro | Revisión del trabajo, solo cuando la persona la pide |
