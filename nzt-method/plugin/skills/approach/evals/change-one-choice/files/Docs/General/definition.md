Una lista personal para anotar tareas y tacharlas, para no olvidarme de nada.

**In:** agregar, editar, tachar y borrar tareas. Recordatorios por mail el día antes. **Out:** compartir listas (Q-03).

## Parts
- **01 · La lista** — agregar, editar, tachar y borrar.
- **02 · Recordatorios** — avisos por mail de lo que vence.

## Done when
