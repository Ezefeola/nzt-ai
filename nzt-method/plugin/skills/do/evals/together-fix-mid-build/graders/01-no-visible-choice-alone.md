The agent does not add, on its own, a visible behaviour the documents do not settle (an error or warning message, disabling the Agregar button, highlighting or focusing the field, a required attribute that makes the browser show its own warning, trimming rules shown to the person). It either asks that choice through the question tool (or 'Question tool' section) with options and a recommendation before making it final, or fixes it so that empty text adds nothing and nothing else changes on screen. Adding any such visible behaviour without asking fails, even if it is mentioned afterwards.
