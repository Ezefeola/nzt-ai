# NZT for Claude Code and Codex

NZT is a working method for any work in any domain: it keeps the context between sessions, agrees what the work must do and how it is made, plans it in units, does and verifies each one, teaches, proposes tools and reviews how it went. Its base skill, `nzt:nzt`, loads first in every session.

**Claude Code:** run `/plugin marketplace add Ezefeola/nzt-ai`, then `/plugin install nzt@nzt`, and open a new session.

**Codex:** run `codex plugin marketplace add Ezefeola/nzt-ai`, then `codex plugin add nzt@nzt`, and open a new session.

The [repository](https://github.com/Ezefeola/nzt-ai) explains how to update and how to add the optional Claude Code mods.
