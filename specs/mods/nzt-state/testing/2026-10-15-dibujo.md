# nzt-state · cómo dibuja el panel cada estado — 2026-10-15

Unidades 159 a 162. Pedido del usuario: ver si la fase actual se ilumina en la línea de
fases, y si se ven la unidad en curso, las pendientes y el resto.

**Con qué se corrió:** el arnés de `claude plugin test` (Claude Code 2.1.299). Monta el panel
en la superficie `terminal` (80×60) y vuelca el árbol dibujado: cada texto con su color, en
negrita (`b`), atenuado (`dim`) o tachado. El estado se le pasa al panel en lugar del archivo.
**No es una sesión en vivo:** prueba qué dibuja el panel, no cómo lo pinta la terminal ni
cómo se lee a simple vista. El test temporal que volcaba el árbol se borró al cerrar la 162.

**Datos:** dos estados escritos para la prueba (E-01 y E-02), el demo
`mods/nzt-state/demo/Plan/state.json` (E-03) y el demo con una sola cosa rota en cada caso
(E-04 a E-06). No hay datos para crear ni para limpiar.

### E-01 · tres fases en curso
- **Corrida 2026-10-15 · sin regla, no es un fallo.** Las tres fases se dibujan iluminadas,
  invertidas y en negrita (`● UX`, `● Build`, `● Verificación`), y el panel no avisa nada. El
