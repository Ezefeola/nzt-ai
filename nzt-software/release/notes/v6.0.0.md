## NZT v6.0.0

En Claude Code el plugin pasa a llamarse `nzt-software`, y sus skills van sin el prefijo `nzt-`: `/nzt-software:nzt`, `/nzt-software:build`, `/nzt-software:verify`. Si tenés el plugin `nzt` de la v5, ejecutá `/plugin uninstall nzt@nzt`, después `/plugin install nzt-software@nzt`, y abrí una sesión nueva. Los mods no cambian de nombre. En Codex y con el instalador las skills siguen llamándose `nzt-<fase>`.

El agente ahora puede ofrecerte un MCP o un plugin en cualquier fase, cuando el trabajo saldría mejor con él. Lo busca en las fuentes oficiales, lo instala en el proyecto solo si aceptás, y lo anota en `Docs/agent-tools.md`. Una herramienta que rechazás no te la vuelve a ofrecer.

Se retiran los packs, `nzt-games` y el subcomando `nzt-ai project`. `Docs/Architecture/tech.md` ya no tiene la línea `packs:`: las reglas de software se eligen por las tecnologías y prácticas que declara. NZT queda para software.

Encontrás los comandos para cada plataforma en la [guía de instalación](https://github.com/Ezefeola/nzt-ai/blob/v6.0.0/nzt-software/README.md#installation).
