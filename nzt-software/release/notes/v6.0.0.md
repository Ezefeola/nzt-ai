## NZT v6.0.0

NZT se instala de una sola forma: como el plugin `nzt-software`, en Claude Code y en Codex. Se retira el instalador `nzt-ai` con sus comandos de una línea (`irm`, `curl`) y sus binarios.

- **Claude Code:** `/plugin marketplace add Ezefeola/nzt-ai`, después `/plugin install nzt-software@nzt`, y abrí una sesión nueva.
- **Codex:** `codex plugin marketplace add Ezefeola/nzt-ai`, después `codex plugin add nzt-software@nzt`, y abrí una sesión nueva.

Dentro del plugin las skills van sin el prefijo `nzt-`: `nzt-software:nzt`, `nzt-software:build`, `nzt-software:verify`. En Claude Code se invocan con `/nzt-software:<skill>` y en Codex con `$nzt-software:<skill>`.

**Si venís de una versión anterior**, sacá primero lo que tenías, para que el método no se cargue dos veces:

- Con el plugin `nzt` de la v5 en Claude Code: `/plugin uninstall nzt@nzt`.
- Con el instalador de una línea (`irm` o `curl`): no dejó una copia en tu máquina, así que se corre otra vez su script de la v5.0.0 en modo desinstalar, fijado en la v5.0.0 porque el último release ya no tiene binarios. En Claude Code, `NZT_MODS=none` deja tus mods, que siguen siendo los mismos plugins:
  - Windows: `$env:NZT_UNINSTALL='1'; $env:NZT_VERSION='v5.0.0'; $env:NZT_MODS='none'; irm https://github.com/Ezefeola/nzt-ai/releases/download/v5.0.0/install-claude.ps1 | iex`
  - macOS y Linux: `curl -fsSL https://github.com/Ezefeola/nzt-ai/releases/download/v5.0.0/install-claude.sh | NZT_UNINSTALL=1 NZT_VERSION=v5.0.0 NZT_MODS=none sh`
  - Codex: lo mismo con `install-codex.ps1` o `install-codex.sh`, sin `NZT_MODS`.

El agente ahora puede ofrecerte un MCP o un plugin en cualquier fase, cuando el trabajo saldría mejor con él. Lo busca en las fuentes oficiales, lo instala en el proyecto solo si aceptás, y lo anota en `Docs/agent-tools.md`. Una herramienta que rechazás no te la vuelve a ofrecer.

Se retiran los packs, `nzt-games` y el subcomando `nzt-ai project`. `Docs/Architecture/tech.md` ya no tiene la línea `packs:`: las reglas de software se eligen por las tecnologías y prácticas que declara. NZT queda para software.

Encontrás los pasos en la [guía de instalación](https://github.com/Ezefeola/nzt-ai/blob/v6.0.0/nzt-software/README.md#installation).
