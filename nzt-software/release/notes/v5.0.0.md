## NZT v5.0.0

En Claude Code ya podés instalar el método como plugin. Agregá el marketplace con `/plugin marketplace add Ezefeola/nzt-ai`, instalá `/plugin install nzt@nzt` y abrí una sesión nueva. Incluye los subagentes y los packs `nzt-software` y `nzt-games`.

En Claude Code y Codex también podés usar la línea de instalación de tu proveedor. Si venís de v4, repetí esa línea para actualizar. El kernel pasa a la skill `nzt` y el instalador retira el bloque que administraba en tu archivo de instrucciones, conservando tu texto. El chequeo de estado ahora vive en `nzt-plan`.

Elegí una sola vía para instalar el método en Claude Code. Si pasás del instalador al plugin, ejecutá primero `nzt-ai uninstall --provider claude-code --mods none` para conservar tus mods. Encontrás los comandos para cada plataforma en la [guía de instalación](https://github.com/Ezefeola/nzt-ai/blob/v5.0.0/README.md#instalación).
